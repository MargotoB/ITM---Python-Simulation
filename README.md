This project is a Python simulation of ultrasound diagnostic signal processing, developed as coursework for “Information Technologies in Medicine” at the Technical University of Sofia. It implements the complete B-mode imaging chain: synthetic RF echo generation from a scatterer phantom, band-pass FIR filtering, time gain compensation (TGC), envelope detection via the Hilbert transform, log compression and speckle reduction with a Lee filter. The analog side is modeled as well: a receive channel based on the TI AFE5809 front end, driven by a TGC control circuit taken from the TI TIDA-01427 reference design, with every stage simulated through transfer functions derived from its component values. Image quality is evaluated quantitatively using speckle SNR, contrast, CNR and axial/lateral resolution, and the results agree with theory (e.g. a speckle SNR of 1.84 vs. the expected 1.91). All code uses NumPy, SciPy and Matplotlib, and the results are fully reproducible.
